# Supplementary Table S1 — Full source list for the multivalent polymer electrolyte dataset

All **85 distinct literature sources** behind the 137-row dataset used in this paper (2 alkaline/KOH-soak rows, which were excluded from modeling, are also excluded from this source list). Sources are sorted alphabetically by citation text. `n_rows` = number of data points this source contributed. Each source was individually reviewed and flagged `LOW CONFIDENCE` if its own citation (authors, journal, or DOI) could not be confirmed, or if its conductivity value is explicitly sourced secondarily (via a review paper's comparison table rather than the primary paper itself); a source with a complete, primary citation is not flagged merely because some ancillary experimental detail (exact concentration, temperature) is unconfirmed. These should be independently re-verified before this dataset is used beyond a feasibility demonstration.

**24 of 85 sources (28%) are flagged low-confidence.**
